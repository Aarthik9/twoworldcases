# AURELIS — Two Worlds Phone Cases

A premium dummy ecommerce prototype based on the supplied creative brief.

## Run

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal.

## Included
- Cinematic two-door entrance
- Her World / His World visual systems
- Responsive product collections
- Product detail pages
- Custom case mini design studio
- Cart placeholder
- Framer Motion interaction
- Dummy product data in `src/data/products.js`
- Reusable components/pages in a compact prototype structure

No real payments are implemented.
